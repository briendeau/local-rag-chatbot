RAG stands for Retrieval Augmented Generation. It covers the 3 step process for building a custom llm chatbot that does search on local data/documents creates an augmented prompt with custom rules and context based on scored relevance, and then generates a chat response you can question using that context. An embedding is a vector of meaning (list of floats). Cosine ranks closeness between a query vector and a data vector.  RAG retreives the top chunks, sticks them in the prompt and answers only from that context or will say don't know. Chunking splits a file so search returns a paragraph and not the whole document.
