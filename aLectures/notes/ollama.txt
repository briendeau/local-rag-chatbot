Ollama is an open source software platform and local server that hosts and runs models like the llm model and embedding model. You can download, run, and manage llms directly on your machine. It is similar to a package manager built specifically for artificial intelligence. It handles complex tasks for you so you can host and run powerful ai models locally without needing an internet connection or api subscription. It runs on at http://localhost:11434/v1. The chat functionality uses endpoint /chat/completions with llama3.2. Embeddings use /embeddings and the nomic-embed-text model. You make post requests to specific endpoints to get back response data.
