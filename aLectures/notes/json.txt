json is javascript object notation. A data exchange format consisting of value types, typically key value pairs, or arrays formatted as a character string in utf-8. Programs can parse json to turn it back into a native data structure in a programming language. You can turn objects into json for sending over the wire using json.dump creates a file, json.dumps creates a string, and pass in your dictionary or list. You can then take that parsed object back and use a from_dict function to recreate the object with its methods using a @classmethod from your class. json.load() turns the json file object into a python object. you cannot just dump a player into json because the methods are not simple value data they depend on other input and being called. to_dict is a way to extract the non method data into a format that can be turned into json.
